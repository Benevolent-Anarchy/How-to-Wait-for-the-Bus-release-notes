# How to Wait for the Bus 1.0.6

<!-- sourceCommit: 5af536febcaf5935e8e6feadf24d67c3988e05a0; previousCommit: 84dc9ad276b8dba4aa9a22adfc51e183ba5541fc -->

This distribution update keeps version 1.0.6. Players already using 1.0.6 on Steam
or itch have no new gameplay changes. The Google Play update catches up from
1.0.0; check the availability record below for its review and rollout status.

## Changes since 1.0.0

- Added Simplified Chinese, available from the language selector in Settings.
- Improved text layout when translated text uses a fallback font.
- On a controller, the Menu button opens Settings and the View button backs out
  of a dialog or returns to the main menu. Escape also backs out.
- Disconnecting the controller in use pauses the game when the board comes to
  rest, giving you time to reconnect or switch input devices.

## Desktop and Steam

- The mouse cursor hides during controller use and returns when you move or
  click the mouse.
- F11 switches between fullscreen and the previous window mode. Steam Big
  Picture launches open in fullscreen.
- Opening the Steam overlay pauses the game and keeps overlay input from
  affecting play underneath it. Closing the overlay leaves the game paused
  until you return to it.
